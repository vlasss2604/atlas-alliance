==================================================
1. PRIMARY BETA OBJECTIVE
==================================================

Основная задача:

NEW PROJECT
→ understand project
→ confirm Topic
→ retrieve existing Topic Research Pattern
→ determine what is already known and what is unknown
→ discover the project's authoritative information sources
→ build an adaptive research plan
→ research only what is actually required
→ collect fresh evidence
→ reconcile evidence
→ produce a correct Proof
→ review how the research was performed
→ save useful project-specific research experience
→ use that experience in future Proofs about this project.

ATLAS must NOT simply search the web broadly from scratch every time.

The existing Topic Pattern should guide the investigation.

Fresh Evidence must still verify the answer.

Core rule:

Research Memory guides.
Fresh Evidence verifies.

==================================================
2. WHAT "LEARNING A NEW PROJECT" ACTUALLY MEANS
==================================================

Learning a project does NOT mean saving a summary about the project.

ATLAS must learn HOW TO RESEARCH that project.

For a new project it should gradually discover and preserve useful things such as:

- official documentation;
- official governance;
- official dashboards;
- protocol-native data;
- relevant contracts / addresses where applicable;
- strong primary sources;
- terminology used by the project;
- metric definitions;
- known high-quality queries;
- queries that failed;
- dead-end sources;
- duplicate routes;
- data that becomes stale quickly;
- current-status sources;
- where execution can actually be verified;
- special project-specific research caveats.

This becomes Project Memory.

The purpose of Project Memory is:

First Proof:
ATLAS learns the research environment of the project.

Later Proof:
ATLAS should not rediscover the same environment from zero.
