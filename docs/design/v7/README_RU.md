# ATLAS PROOF — полный пак для Claude Code

Всё в одном архиве: дизайн V7, все экраны, демо-режим для рекламы, план работ и оценки по времени.

## Что внутри

- **HANDOFF.md** — главное задание по дизайну (на английском, так Claude Code точнее работает с репозиторием): правила, порядок шагов, разбор каждого экрана, все новые тексты EN/RU, решения, которые он должен спросить у вас.
- **PLAN_AND_ESTIMATES.md** — порядок работ, аудит, который он делает первым, и оценки времени: отдельно основное приложение и отдельно демо.
- **DEMO_MODE_SPEC.md** — демо-режим по рекламной ссылке: вход через бота, путь пользователя, промокоды, что демо делать нельзя.
- **screenshots/** — 51 состояние экранов, эталон картинки. **screens/index.html** — открой в браузере, там все экраны плиткой.
- **source/** — исходники макетов с логикой.
- **tokens/atlas-v7.css** — цвета, шрифт Inter, разрешённые анимации.
- **assets/** — щит AP и логотипы. **motion/** — раскадровки спокойного появления экранов.

## Структура продукта (вписана в задание)

- **Бесплатно:** пять проектов-витрин (Raydium, Pump.fun, Lido, Jupiter, Jito; Aave запасной), у каждого один опубликованный Proof только для чтения. Свои исследования и Pulse закрыты.
- **Подписка** (Telegram Stars): свои исследования и Pulse. **Цена ещё не утверждена, оплату пока не делаем** — подключим отдельным этапом. $49 — рабочая цифра.
- **Демо** — то же приложение, включается только по рекламной ссылке: приветствие → проект → вопрос → повтор исследования ~10 с → Proof → уведомление Pulse → Pulse-демо → «Получить скидку −20%» → промокод от бота. Цены в демо нет.
- **Никакой беты.** Слово «beta» убирается из интерфейса.

## Порядок работ и сроки (оценка, не замер)

| Этап | Что | Рабочие дни |
|---|---|---|
| 0 | Аудит, ничего не меняя | 0,5–1 |
| 1 | Дизайн всех экранов с анимацией | 7–10 |
| 1b | Подписка через Stars, убрать «бету» — отложено, пока не утверждена цена | 2–3 |
| 2 | Доработка движка | по итогам аудита |
| 3 | Пять проектов: прогоны, ваша проверка, публикация | 2–3 + около недели на прогоны и ваше ревью |
| 4 | Демо-режим для рекламы | 4–6 |
| 5 | Скриншоты, ролик, запуск | 2–4 |

**Основное приложение (1 + 1b + 3, без движка): ≈ 11–16 рабочих дней.**
**Демо для рекламы: ≈ 4–6 рабочих дней** (после того, как опубликован хотя бы Raydium).
Рабочий день — это 4–6 часов сессий Claude Code; плюс время на ваши проверки. После аудита Claude Code пришлёт свои цифры — им верить больше.

## Как передать (3 шага)

1. Скачайте `ATLAS_PROOF_design_handoff.zip` из чата (попадёт в «Загрузки»).
2. Откройте Claude Code в папке проекта (`~/src/atlas-proof`, ветка `claude/phase-5-research-memory`).
3. Вставьте ему сообщение:

```
Задача: перенести утверждённый дизайн V7 в приложение и подготовить демо-режим. Полный пак здесь:
/mnt/c/Users/user/Downloads/ATLAS_PROOF_design_handoff.zip
Распакуй в docs/design/v7/ и прочитай по порядку: HANDOFF.md, PLAN_AND_ESTIMATES.md, DEMO_MODE_SPEC.md.

Порядок: 1) дизайн приложения с анимацией, максимально быстро и точно по макетам; 2) доработка движка; 3) пять проектов; 4) демо-режим; 5) скриншоты и запуск.

Сейчас — только этап 0: аудит по разделу 1 PLAN_AND_ESTIMATES.md. Код не меняй. Результат — docs/design/v7/AUDIT_REPORT.md простым языком и твоя таблица сроков.

Правила:
- Research Engine и Proof logic не трогать. Никаких live calls.
- Ничего не выдумывать: цифры и тексты — из данных и i18n, значения в макетах — примеры.
- stash@{0} и незакоммиченную работу D-179 не трогать.
- Код — только после моего «go» на каждый этап. Новая ветка от claude/phase-5-research-memory (например claude/v7-design), коммит на каждый шаг с зелёными тестами.
- Push и merge — только с моего разрешения.
```

Если имя пользователя Windows другое — поправьте путь `/mnt/c/Users/user/Downloads/`.

## Решения, которые он спросит у вас

1. Русская подпись в шапке (английская решена: CRYPTO VERIFICATION · ECONOMICS). Шрифт решён: Inter.
2. Кнопка «Open Proof» после исследования или авто-переход, как сейчас.
3. Строки «что сейчас делает ATLAS» и источники вокруг сканера — нужны новые события движка, отдельная задача.
4. Где остановилось исследование при сбое/отмене — изменение логики, отдельно.
5. Кольцо и лента цепочки на Proof заменяют текущую карту доказательств.
6. Фильтры в библиотеке Proofs. Профиль — сверить с настоящей страницей. Имя/фото — нужно ли.
7. Есть ли у подписки лимит исследований (показывать ли счётчик «Осталось 3»).
8. Цена подписки — пока не утверждена, оплату не делаем до вашего решения.
9. Какие пять исследований публикуете — решаете вы, по одному, командой в боте.
10. Отправлять ли настоящее сообщение бота в момент уведомления в демо (в макете — только окно внутри приложения).
11. Формат промокода, тексты сообщений бота, дата запуска, одно сообщение «ещё готовим», если запуск сдвинется.
12. Jupiter и Jito: если их вопрос не проверяется текущими источниками — остаются «на проверке качества», вопрос не упрощаем ради вердикта.

Анимации — спокойные, как у серьёзного продукта: короткие появления, без вечных украшений (раздел 4.9 HANDOFF.md).
